# Камера: монтаж і захоплення кадрів

| Файл | Призначення |
|---|---|
| `camera_config.yaml` | драйвер, роздільність, fps, фіксована експозиція |
| `capture.py` | захоплення кадрів із міткою часу; перевірка fps і джиттера |

## Швидка перевірка камери
```bash
pip install opencv-python pyyaml        # на Jetson: opencv з JetPack
python3 capture.py --config camera_config.yaml --seconds 5
# кадрів 150, fps 30.0, інтервал мс: середній 33.3, макс 36.1, розкид (std) 0.4
```
`--preview` показує вікно. Без заліза: у конфігу `backend: synthetic`.

## Вимоги до камери (звірити з ТЗ та замовником)
- Моно або кольорова з перетворенням у gray; **глобальний затвор** бажаний
  (rolling shutter псує і калібрування, і оптичний потік на швидкості).
- 640x480...1280x720, >=30 fps *стабільно* (перевір `capture.py`).
- Фокус **зафіксований** на робочу відстань польоту (висота, а не стіл!).
  Автофокус і автоекспозиція вимкнені: інакше внутрішні параметри "пливуть".
- Інтерфейс: USB3/UVC (простіше) або CSI (менша затримка, `backend: gstreamer`).

## Монтаж
Алгоритм у `vio/vio_frontend.py` припускає камеру, що **дивиться вниз**, з орієнтацією:
вісь x кадру = права сторона дрона, вісь y кадру = назад. Тобто верх зображення
дивиться **назад** по ходу дрона. Якщо змонтуєш інакше, Людина 3 мусить змінити
`flow_rot` і `v_body` разом. Після калібрування `make_report.py` порахує відхилення
від цього монтажу й попередить, якщо воно > 10 град.

- Жорстке кріплення, подалі від пропелерів, з віброізоляцією (гума/пінопласт під
  платою камери), але **без** люфту відносно польотного контролера, інакше `T_cam_imu` не стабільна.
- Камера й контролер із IMU на одній рамі; виміряй відстань між ними лінійкою
  (для перевірки Kalibr: має збігатися в межах сантиметрів).
- Захист об'єктива від пилу/бризок, кабель зафіксований (не тягне камеру).

калібрування **недійсне** - повторити (`calibration/README.md`).
