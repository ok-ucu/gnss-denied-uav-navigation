# Моніторинг інтеграції VIO з ArduPilot

## 1. Опис модуля

Цей модуль призначений для моніторингу та перевірки інтеграції системи візуально-інерціальної одометрії (Visual-Inertial Odometry, VIO) з автопілотом ArduPilot у симуляційному середовищі SITL.

Основна мета — забезпечити можливість спостереження за станом навігаційної системи, оцінювати невизначеність позиції та аналізувати поведінку автопілота під час погіршення або втрати навігаційних даних.

Для отримання телеметрії використовується протокол MAVLink та Python-бібліотека `pymavlink`.

## 2. Основні функції

Розроблений інструмент `check_integration.py` призначений для виконання таких завдань:

- Підключення до ArduPilot SITL через MAVLink.
- Отримання інформації про стан фільтра EKF.
- Моніторинг невизначеності горизонтальної позиції дрона.
- Відстеження змін режимів польоту.
- Реєстрація попереджень і повідомлень автопілота.
- Збереження телеметрії у CSV-файл для подальшого аналізу.

Інструмент використовується для діагностики й перевірки інтеграції та не замінює повноцінний вузол-конвертер ROS2/MAVROS.

## 3. Реалізація

Основний файл модуля — `check_integration.py`.

Для взаємодії з автопілотом використовується бібліотека `pymavlink`, яка забезпечує обмін повідомленнями за протоколом MAVLink.

Програма обробляє такі типи повідомлень:

| Повідомлення | Призначення |
|---|---|
| `HEARTBEAT` | Визначення поточного режиму польоту |
| `EKF_STATUS_REPORT` | Отримання інформації про стан EKF та невизначеність позиції |
| `LOCAL_POSITION_NED` | Отримання локальних координат дрона |
| `STATUSTEXT` | Реєстрація попереджень і повідомлень автопілота |

Для оцінювання невизначеності позиції використовується поле `pos_horiz_variance` повідомлення `EKF_STATUS_REPORT`.

Отримані дані зберігаються у CSV-файл, що дозволяє використовувати їх для подальшого аналізу роботи навігаційної системи.

## 4. Встановлення залежностей

Для запуску необхідний Python та бібліотека `pymavlink`.

Створення віртуального середовища:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Встановлення залежності:

```bash
python -m pip install pymavlink
```

## 5. Запуск

Перед запуском необхідно запустити ArduPilot SITL та налаштувати передавання MAVLink-телеметрії на UDP-порт `14552`.

Із кореневої директорії проєкту виконати:

```bash
python integration/check_integration.py --conn udpin:127.0.0.1:14552
```

Після встановлення з'єднання програма очікує повідомлення автопілота та реєструє отриману телеметрію.

Для завершення роботи використовується `Ctrl + C`.

## 6. Перевірка реалізації

На поточному етапі виконано такі перевірки:

- Перевірено синтаксичну коректність Python-скрипта.
- Перевірено запуск інтерфейсу командного рядка через параметр `--help`.
- Перевірено можливість імпорту бібліотеки `pymavlink`.

Повноцінне інтеграційне тестування з ArduPilot SITL поки не завершено.

Під час підготовки середовища виникла помилка збірки Docker-образу, пов'язана з невідповідністю контрольних сум пакетів Ubuntu (`Hash Sum mismatch`).

Ця проблема перешкодила запуску повного симуляційного стенду та перевірці отримання телеметрії від реального процесу SITL.

Тому реакція EKF на зміну невизначеності VIO та поведінка автопілота під час втрати навігації потребують подальшої експериментальної перевірки.

## 7. Подальші кроки

Для завершення інтеграції необхідно:

1. Усунути проблему збірки Docker-образу та запустити SITL.
2. Перевірити надходження MAVLink-телеметрії.
3. Дослідити зміну показників EKF під час погіршення якості VIO.
4. Перевірити реакцію автопілота на втрату зовнішніх навігаційних даних.
5. Проаналізувати отримані результати.
6. Реалізувати або інтегрувати ROS2/MAVROS-міст для передавання одометрії VIO до ArduPilot.

## 8. Результат роботи

Реалізований модуль створює основу для перевірки взаємодії VIO з ArduPilot, зокрема для дослідження невизначеності позиції, зміни режимів польоту та реакції автопілота на навігаційні збої.
