# Логування польотів ArduPilot

## Де лежать логи
- SITL у Docker: `run` монтує папку `~/sitl-logs` у `/home/dev/ardupilot/ArduCopter/logs`.
  Файли `0000000N.BIN`, плюс `LASTLOG.TXT` (номер останнього).
- Реальний контролер: логи пишуться на SD-карту контролера
  (шлях і спосіб вивантаження звірити для вашого контролера).

## Коли пишеться
Лише коли дрон озброєний (`arm`). Перший рядок логу: `Arming motors`.
Параметри: `LOG_BACKEND_TYPE` = 1, `LOG_BITMASK` = 180222, `LOG_DISARMED` = 0.

## Як отримати GPS-трек (ground truth)
```bash
python3 log_to_gps_csv.py ~/sitl-logs/00000001.BIN gps_track.csv
```
Колонки CSV:
| Колонка | Зміст |
|---|---|
| t_s | секунди від першої GPS-точки |
| gps_time_s | абсолютний GPS-час: для вирівнювання з камерою й VIO |
| lat, lon, alt_m | координати з GPS |
| north_m, east_m, up_m | метри відносно першої точки |

Частота GPS у SITL: ~5 Гц (крок 0,2 с). Точки без 3D-фіксації відкидаються.

## Які повідомлення використовуємо
GPS (ground truth), IMU, ATT, POS, BAT, MODE, MSG (події: failsafe, зміни режимів).
У режимі зовнішньої навігації додатково з'являються VISO / VISP.

## Події безпеки з логу
```bash
# повідомлення автопілота з часом
python3 -c "from pymavlink import mavutil; l=mavutil.mavlink_connection('FILE.BIN'); ..."
```
(готовий скрипт для подій: див. розділ про безпеку.)

## Відомі обмеження
- Вирівнювання часу між логом ArduPilot і датасетом камери потребує узгодженої
  синхронізації (Людина 2). GPS-час із цього файлу є опорним.
- У SITL GPS-час симулюється й береться з системного годинника.
