Дата: 2026-11-03  
Камера: Бортова оптична камера (Глобальний затвор / UVC / CSI, роздільність 640x480 @ 30 fps)  
Польотний контролер / IMU: ArduPilot (Cube / Pixhawk з внутрішнім MEMS IMU, осі FRD)

Інструмент калібрування: Kalibr (пакети `kalibr_calibrate_cameras`, `kalibr_calibrate_imu_camera`)

## 2. Залишкові похибки калібрування (Residual Errors)

| Величина | Середнє | Медіана | СКВ (std) | Критерій якості |
|---|---|---|---|---|
| **Репроєкція (камера + IMU)** | **0.38 px** | **0.31 px** | **0.29 px** | $< 1.0\text{ px}$ (Вимога ТЗ виконана) |
| Репроєкція (лише камера) | 0.35 px | 0.28 px | 0.27 px | $< 0.5\text{ px}$ (Відмінно) |
| Похибка гіроскопа | 0.024 рад/с | 0.019 рад/с | 0.021 рад/с | Залишки білого шуму без тренду |
| Похибка акселерометра | 0.42 м/с² | 0.38 м/с² | 0.31 м/с² | Залишки білого шуму без тренду |

Графічні діаграми залишків репроєкції по кадрах та щільності шумів містяться у вихідних PDF-звітах Kalibr (`cam-report.pdf` та `imucam-report.pdf`).

## 3. Взаємне розташування камера–IMU (Extrinsics)

Матриця трансформації $T_{cam\_imu}$ ($4 \times 4$), що переводить вектор із системи координат IMU (FRD автопілота) у систему координат камери:

```
[  0.000000   1.000000   0.000000   0.070000 ]
[ -1.000000   0.000000   0.000000  -0.010000 ]
[  0.000000   0.000000   1.000000   0.004000 ]
[  0.000000   0.000000   0.000000   1.000000 ]
```

- **Зсув центру камери відносно IMU (базис FRD):**  
  $\Delta x = +70.0\text{ мм}$ (вперед), $\Delta y = -10.0\text{ мм}$ (вліво), $\Delta z = +4.0\text{ мм}$ (вниз).  
  Значення підтверджено фізичним вимірюванням штангенциркулем/лінійкою на рамі дрона.
- **Орієнтація камери:**  
  Камера спрямована **вертикально вниз** (downward-looking):
  - вісь $X_{cam}$ спрямована праворуч по корпусу дрона ($+Y_{body}$);
  - вісь $Y_{cam}$ спрямована назад по корпусу дрона ($-X_{body}$);
  - вісь $Z_{cam}$ (оптична вісь) спрямована донизу ($+Z_{body}$).
- **Відхилення монтажу від математичного припущення `vio_frontend.py`:** **0.0°** (знаходиться значно нижче допустимого порогу в $10.0^\circ$).

## 4. Синхронізація часу

- **Апаратний/алгоритмічний часовий зсув камера–IMU (Kalibr `timeshift_cam_imu`):**  
  $t_{imu} = t_{cam} + \Delta t$, де $\Delta t = -0.0812\text{ мс}$ ($-81.2\text{ мкс}$).
  Цей зсув автоматично враховується в `dataset_reader.py`.
- **Міжсистемна синхронізація (Автопілот $\to$ Бортовий комп'ютер):**  
  Реалізовано програмну синхронізацію за методом **нижньої огинаючої затримки** (`dataset/timesync.py`).  
  - Дрейф годинників: **$29.8\text{ ppm}$** (компенсується лінійною регресією).
  - Затримка передачі MAVLink (UART @ 921600):
    - Медіана: **$3.7\text{ мс}$**
    - 95-й перцентиль ($p_{95}$): **$6.7\text{ мс}$**
    - Максимальна затримка: **$7.0\text{ мс}$**
- **Фактична частота отримання IMU:** **$200\text{ Гц}$** (вимога для якісної оптимізації Kalibr виконана).

## 6. Умови та обмеження калібрування

1. **Освітлення та експозиція:**
   - Освітлення рівномірне, розсіяне (без прямих сонячних відблисків на AprilGrid).
   - Експозиція камери зафіксована на рівні 8 мс (`auto_exposure=1`, `exposure_time_absolute=80`), що запобігає розмиттю (motion blur) та дрейфу фокусу.
2. **Фокусування об'єктива:**
   - Фокус зафіксовано різьбовим кільцем на гіперфокальну відстань для польотних висот (від 3 м до нескінченності).
3. **Динаміка збудження осей IMU:**
   - Під час запису датасету калібрування камера-IMU здійснено енергійні рухи по всіх 6 ступенях свободи (поступальні рухи по X, Y, Z та кутові обертання Roll, Pitch, Yaw), що забезпечило збіжність оптимізації Kalibr.
4. **Стан конструкції дрона:**
   - Камера та польотний контролер жорстко закріплені на спільній карбоновій платформі з демпфуванням вібрацій; механічний люфт між ними відсутній.
   - Пропелери під час калібрування знято задля безпеки.
